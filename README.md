# CampusAssist 

### Making Everyday Campus Activities Easier

CampusAssist is a web-based project developed to make everyday activities on a college campus simpler and more organised.

Instead of depending on manual enquiries, notice boards or informal messages, students and staff can use one platform to check classroom availability, report lost and found items, and raise technical issues.

##  Features

### 1. Classroom and Laboratory Availability
- Teaching staff can check which classrooms and labs are available or occupied.
- Room status is displayed clearly to avoid confusion.
- Staff can find suitable rooms for extra classes and other academic activities.
- Authorised staff can update the status of rooms.
- Users can select their course (BCA, BCS or BTech) before proceeding with classroom and lab selection.

### 2. Lost and Found
- Students can report items they have lost or found.
- They can upload pictures and add descriptions to help identify belongings.
- Users can search through the reported items.
- This makes it easier for students to connect with finders and recover their belongings.

### 3. Technical Issue Reporting
- Teaching staff can report problems related to projectors, computers, networks and laboratory equipment.
- They can provide details about the issue, its location and priority.
- Technical staff can view and track the reported complaints.
- The status of an issue can be checked as Pending or Resolved.

## User Roles

CampusAssist has different sections based on the user's role:

- **Student:** Can access the Lost and Found section to report and search for items.
- **Teaching Staff:** Can check classroom availability and report technical issues.
- **Technical Staff:** Can view reported technical issues and track their progress.
- **Admin:** Can monitor the different modules and view system reports.

## How to Run the Project

1. Install **XAMPP** on your computer.
2. Start Apache and MySQL from the XAMPP Control Panel.
3. Copy the CampusAssist project folder into the `htdocs` folder.
4. Open phpMyAdmin and create the required database.
5. Import the database if an SQL file is available.
6. Check the PHP database connection settings and update them according to your local MySQL configuration.
7. Open your browser and visit:

   `http://localhost/CampusAssist/first_page.html`

##  Current Limitations

- No instant notifications for room bookings, lost items or resolved complaints.
- User access control is currently basic.
- Data security can be improved further.
- Some updates depend on manual input.
- There is no dedicated mobile application.

##  Future Enhancements

Some features that could be added to improve CampusAssist in the future include:

- Real-time notifications through email or in-app alerts.
- More advanced role-based access control.
- Improved authentication and database security.
- Better support for more users and multiple campuses.
- A dedicated mobile application.
